# 《幸存者偏差》视觉 Token

> 本步只定视觉系统 + 验证开头 10 秒。全片暂不推进。

## 气质一句话

深色知识短片：细线结构、琥珀金标「新信息」、冷蓝标「已知结构」。像解谜，不像课堂 PPT。

## 颜色

| Token | Hex | 用途 |
| --- | --- | --- |
| `bg` | `#0B0D10` | 主背景 |
| `bgSoft` | `#12151A` | 弱分层 |
| `structure` | `#7EB6FF` | 结构线、已知轮廓 |
| `surprise` | `#E8B86D` | 新信息、弹孔、金句强调 |
| `danger` | `#FF6B6B` | 错误、要害、否定 |
| `text` | `#F2F4F7` | 主字幕 |
| `muted` | `rgba(242,244,247,0.55)` | 辅助说明 |
| `line` | `rgba(126,182,255,0.35)` | 细线 / 网格 |
| `ghost` | `rgba(242,244,247,0.18)` | 幽灵飞机、失败样本 |

## 字体

| 角色 | 字体 | 用法 |
| --- | --- | --- |
| 标题 / 金句 | Noto Serif SC | 「错了。」片名、收束句 |
| 字幕 / UI | Noto Sans SC | 叙事字幕、选项、英文小字 |

## 动效规则

1. 字幕：约 8–12 帧淡入，轻微上移  
2. 弹孔：逐个点亮，不一次性铺满  
3. 「错了。」：弹簧放大 + 重拍感  
4. 禁止：粒子烟花、多层阴影、圆角大卡片堆砌

## 开头 10 秒要验证什么

- [ ] 深色细线气质是否立住  
- [ ] 弹孔点亮是否有「被提问」的感觉  
- [ ] 0:09.5「错了。」是否够狠  
- [ ] 字幕是否好读（字号/位置）
